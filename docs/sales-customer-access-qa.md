## 独立审查及修复

独立审查覆盖 dfe271d..e1af332，未发现确认的认证绕过或跨销售服务端泄露，发现两项 P2：

- 历史客户缺 revision 时原系统投影为 0，转交逻辑却要求大于 0。回归测试先复现 HTTP 400，然后统一为既有 0 起始约定，历史客户可分配。
- Excel 新增来源/负责销售列，但导出没有加载名称。回归测试复现空单元格，再提取共享 withSalespersonNames 投影供列表和导出使用；测试验证两列都有名称。

## 扩展与发布限制

账号、HTTP 认证、归属、客户投影和页面分别独立；不可变销售 ID、独立来源/负责人、转交审计及 revision 为后续团队和跟进功能提供接入点。没有创建未使用的未来模块。

仍为单实例部署；反向代理来源限流可能共享额度；正式运行需要 HTTPS、精确 Origin、持久数据库和写权限核验。浏览器已接收的信息无法被远程收回。匿名浏览不能自动识别真实客户身份，手机号未做验证。

演示推广码只存在本地；正式域名二维码不可直接对外分发。上线后在正式后台创建销售和账号。部署及备份说明见 [使用文档](sales-customer-access.md)。
