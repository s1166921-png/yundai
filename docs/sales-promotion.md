# 销售专属二维码与访问统计

第一版由管理员统一生成销售推广二维码，销售无需独立账号。客户访问网站时不需要登录或额外填表。

## 使用

1. 打开现有客户后台，点击“销售推广”，或直接访问 /admin/promotions。
2. 使用原有管理员账户、密码读取数据。凭据仅用于当前页面请求，不保存到浏览器存储；不要把管理员凭据交给销售。
3. 填写销售姓名及可选内部备注，点击“添加并生成推广码”。
4. 在该销售一行复制链接，或点击“二维码”后下载 PNG。图片内容与链接相同。
5. 通过开始/结束日期查询期间访问次数；同时显示全历史累计次数和最近访问时间。
6. 改名保留原推广码和统计。停用保留历史数据，原链接仍可浏览网站，但不再增加统计；重新启用后恢复计数。

## 统计口径

- 一个带有效 ref 参数、且页面可见的页面加载算一次推广访问。刷新或重新打开是新的访问。
- 同一次加载的网络重试复用 eventId，服务端只记一次。失败最多重试一次；追踪失败不影响测评。
- 这不是扫码次数、独立访客数或真实客户数。不执行网页脚本的请求不计数，可以减少预览机器人误报，但不保证排除所有机器人。
- 未填写资料的访问保持匿名，不获取姓名、手机号、微信标识或设备指纹。
- 转发二维码/链接后的访问仍归于原推广码。推广码不是身份凭据。
- 上海时区自然日统计；结束日期包含整日。最近访问时间和累计值不因日期筛选改变。
- 原始事件超过 90 天转为每日汇总，汇总保留历史次数。
- 客户端事件 ID 时间须在服务器时间前后 24 小时内。设备时钟严重错误会导致不计数，网页仍能使用。

## 配置与运行

现有 MEIOU_ADMIN_USER、MEIOU_ADMIN_PASSWORD、MEIOU_ALLOWED_ORIGINS 配置继续使用。

| 环境变量 | 用途 |
|---|---|
| MEIOU_PUBLIC_SITE_URL | 正式 HTTPS 网站根地址，例如 https://yundai.meiouyuncang.com 。必须是域名，不允许路径、查询、片段、账号密码、端口、本地地址或尾点域名。 |
| MEIOU_PROMOTION_DB_PATH | SQLite 文件完整路径；默认与客户文件同目录的 promotions.sqlite。 |

没有正确配置公开域名时仍可管理销售、查看统计，但不能复制推广链接或下载二维码，后台显示具体提示。绝不根据传入 Host 自动生成域名。

本地验证运行时为 Node 24.15.0。推广存储使用 Node 内置 node:sqlite（DatabaseSync），上线前检查生产运行时是否支持：

    node --input-type=module -e "import { DatabaseSync } from 'node:sqlite'; const db=new DatabaseSync(':memory:'); db.close(); console.log('SQLite available')"
    pnpm install --frozen-lockfile
    pnpm build

依赖使用锁文件；pnpm 明确允许 esbuild 的必要构建，拒绝 core-js 的非必要安装脚本。二维码在服务端本地生成，不发送销售数据到外部二维码服务。

## 存储与上线

- 部署到单实例或同一服务器上的持久本地磁盘，不能用临时容器文件系统或多个机器各自独立的 SQLite 文件来提供同一套统计。
- promotions.sqlite、promotions.sqlite-wal、promotions.sqlite-shm 放在非公开数据目录。仅运行服务的账户拥有该目录访问权限。Windows 使用目录 ACL；Unix 还应设置仅服务账户可访问的目录权限。
- 表单客户文件保持原样，不迁移、不写入推广存储。
- 数据库使用 WAL、事务、参数化 SQL。备份用 SQLite 一致性备份，或停止服务、关闭数据库后复制；不要在运行时只复制主文件而忽略 WAL。
- 90 天前的原始事件在下一次推广查询或事件写入时事务归档，闲置系统不会定时唤醒做清理。
- 公共事件接口限制 2 KiB，每个直接 socket 来源 120 次/分钟，全局 3000 次/分钟。不信任任意 X-Forwarded-For。**Nginx 等反向代理可能令所有请求共用同一个来源桶**，当前版本适合小规模试点；上线前按流量评估限制，必要时另行配置可信代理及边缘限流，不能直接相信客户端转发头。
- 确保 /api/admin/promotions/*、/api/promotion/events、/admin/promotions 到达 Node API；推广数据和接口禁止 CDN 缓存。
- 公共事件返回空响应，不暴露销售姓名或备注。销售列表、编辑、二维码下载均需管理员认证。
- 推广数据库不可用时接口返回 503，原产品和客户接口继续工作。

正式发布需备份应用文件及数据，核验域名、Node/SQLite、写入权限、HTTPS、Origin 和反向代理路由。此开发交付未自动发布到生产。回滚代码时保留推广数据库。

## 测试

    node --test test/promotion*.test.js
    node --test --test-timeout=45000 --test-concurrency=1 test/*.test.js
    pnpm build

Windows 不支持 Unix 0600 权限位语义，两项专门的 POSIX 权限测试在 Windows 明确跳过，在 Unix 保持启用；其他客户持久化断言照常执行。SSR 测试关闭不必要的浏览器依赖预扫描，避免测试关闭时后台任务挂起。

后续若开发客户识别，需新增明确的线索/访问关联，而不是将已有匿名浏览记录冒认为特定客户。
